[AI Power Grid](https://aipowergrid.io/) provides an OpenAI-compatible Chat
Completions API backed by remote community-operated workers. Use `ChatOpenAI`
with `base_url="https://api.aipowergrid.io/v1"` and an account-scoped API key;
see the [tested AI Power Grid LangChain
cookbook](https://github.com/AIPowerGrid/grid-provider-integrations/tree/main/langchain-aipg)
for public model discovery, streaming, tool calling, credit errors, and the
plaintext remote-worker privacy boundary.
